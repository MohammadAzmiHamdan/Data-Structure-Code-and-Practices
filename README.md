# Data Structures — C++ Implementations & Practice

A collection of **Data Structures implementations and practical exercises in C++**, created as part of my learning journey in Computer Science and programming.

This repository focuses on understanding how fundamental data structures work internally by implementing them from scratch, working with pointers, dynamic memory allocation, recursion, and object-oriented programming.

---

## 📚 Contents

The repository currently covers the following topics:

### 🔹 Linked Lists

Implementations and practice with different types of linked lists:

* Singly Linked List
* Doubly Linked List
* Circular Linked List
* Linked Queue
* Insertion and deletion operations
* Traversal and node manipulation
* Working with `Node*` and dynamic memory

### 🔹 Stack

Different approaches to implementing stacks:

* Stack using Arrays
* Stack using Linked Lists
* Stack operations such as:

  * `Push`
  * `Pop`
  * `Top`
  * `IsEmpty`

### 🔹 Queue

Practice with queue data structures, including:

* Queue implementation
* Linked Queue
* Enqueue and Dequeue operations
* Front and Rear management

### 🔹 Vector

Practical exercises using the C++ `vector` container and understanding dynamic collections.

### 🔹 Binary Search Tree (BST)

Implementation and practice with Binary Search Trees, including working with:

* Nodes
* Insertion
* Searching
* Tree traversal
* Pointers
* Dynamic memory

### 🔹 Map Data Structure

A practical example using a map to work with **student grades**, demonstrating how key-value data can be stored and accessed.

### 🔹 Recursion

Practical recursion exercises designed to strengthen understanding of:

* Base cases
* Recursive calls
* Call stack
* Problem decomposition

### 🔹 Pointers

Practical exercises focused on understanding:

* Pointers
* Addresses
* Dereferencing
* Pointer arithmetic
* Dynamic memory allocation
* Relationship between pointers and data structures

### 🔹 Union

A practical example demonstrating the C++ `union` data type and how multiple members can share the same memory location.

### 🔹 OOP Revision

Additional exercises for reviewing important **Object-Oriented Programming** concepts in C++ and connecting OOP concepts with data structures.

## 🎯 Why This Repository?

Data structures are one of the fundamental foundations of software development.

Instead of relying only on built-in data structures, this repository is focused on implementing and experimenting with them manually in C++ to develop a deeper understanding of:

> **How data is stored, connected, accessed, and modified in memory.**

This practical approach also helps strengthen problem-solving skills and prepare for more advanced topics in **Algorithms, Competitive Programming, and Software Development**.
